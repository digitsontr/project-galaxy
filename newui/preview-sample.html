Git nedir, neden var?
Git projenin zaman makinesi. Her commit bir fotoğraf; dal (branch) o albümün kopyası — asıl kitabı bozmadan yazarsın.
Bu projede sen: {{ gitBranchName }} dalındasın. Aşağıdaki resimde yeşil çizgi yayınlanan kitap (main), mavi çizgi günlük taslak (develop), mor kesikli çizgi tek bir iş.
Dallanma modeli — her nokta bir commit. Kesikli çizgi henüz birleşmemiş iş.
main = yayın
Kullanıcının gördüğü sürüm. Buraya doğrudan yazma — sadece test edilmiş iş birleşir.
develop = mutfak
Günlük geliştirme. Yeni iş buradan dallanır, bitince buraya döner.
feature = tek iş
“Giriş ekranı” gibi tek konu. Bittiğinde kapanır; dal yaşamaz.
Sıra
1Güncel hali algit pull
2İş dalı açgit switch -c feature/…
3Küçük commitgit commit -m "…"
4Uzağa göndergit push -u origin …
5PR aç, birleştirfeature → develop
6Dalı silgit branch -d …
Komutlar
git status — ne değişti
git diff — satır farkı
git add . — sahneye al
git pull / push — indir / gönder
git switch — dal değiştir
git restore — kaydedilmemişi at
