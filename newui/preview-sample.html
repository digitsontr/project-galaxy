Dallanma modeli — git'i hiç bilmeyen biri için. Her nokta bir commit, kesikli oklar dallanma/birleşmedir.
main
Kararlı, yayınlanan sürüm. Doğrudan buraya yazmazsın — sadece test edilmiş işler birleşir.
develop
Günlük geliştirme dalı. Feature dalları buradan açılır, biten işler buraya döner.
feature/*
Tek bir iş için geçici dal. Kesikli çizgi = henüz birleşmemiş; nokta = commit.
Tipik feature akışı · 6 adım
1develop'u güncelle: git switch develop && git pull — en güncel halden başla.
2Dal aç: git switch -c feature/giris-ekrani — işine özel dal.
3Çalış + commit: küçük anlamlı adımlarla git add -p → git commit -m "…".
4Gönder: git push -u origin feature/giris-ekrani — uzağa yükle.
5PR/MR aç: feature → develop. Ekip inceler, yorum yazar.
6Birleştir + temizle: onay sonrası merge, sonra git branch -d feature/giris-ekrani.
Temel Git Komutları · ne işe yarar
▸ Başlangıç & Durum
git init — bu klasörde yeni git deposu başlat
git clone <url> — uzak depoyu bilgisayarına kopyala
git status — hangi dosyalar değişti/eklendi göster
git log --oneline — commit geçmişini kısa listele
▸ Değişiklikleri Kaydetme
git add . — tüm değişiklikleri sahneye al (commit'e hazırla)
git commit -m "mesaj" — sahnedekileri kalıcı kaydet
git commit --amend — son commit'i düzelt/mesajını değiştir
git diff — henüz kaydedilmemiş satır farklarını gör
▸ Dallanma (Branch)
git branch — mevcut dalları listele
git switch -c <dal> — yeni dal aç ve o dala geç
git switch <dal> — var olan bir dala geç
git merge <dal> — o dalı bulunduğun dala birleştir
git branch -d <dal> — işi biten dalı sil
▸ Uzak Sunucu (Remote)
git remote -v — bağlı uzak adresleri göster
git fetch — uzaktaki yenilikleri indir (birleştirmeden)
git pull — uzaktakini indir + kendi dalınla birleştir
git push — kendi commit'lerini uzağa gönder
git push -u origin <dal> — dalı ilk kez gönder ve takibe al
▸ Geri Alma
git restore <dosya> — dosyadaki kaydedilmemiş değişikliği geri al
git restore --staged <dosya> — dosyayı sahneden çıkar
git reset --soft HEAD~1 — son commit'i geri al (değişiklikler durur)
git revert <hash> — bir commit'i tersine çeviren yeni commit
git stash / stash pop — değişiklikleri geçici sakla / geri getir
▸ İnceleme
git show <hash> — bir commit'in tüm detayını gör
git blame <dosya> — her satırı kim/ne zaman değiştirmiş
git diff <dal1>..<dal2> — iki dal arasındaki farkı gör
İpucu: bir şeyi bozmaktan korkma — commit'lenmiş her şey geri alınabilir.
