Git nedir, neden var?
Git, projenin zaman makinesi. Her commit bir fotoğraf. Günlük iş: güncel hali al, bak, incele, kaydet, gönder. Kitaptaki Git Flow (main/develop/feature/hotfix) çoğu takımda kullanılmaz.

main / varsayılan dal

iş dalı = tek konu
Bir özellik veya düzeltme. Bittiğinde PR ile birleştir, dalı sil. Yaşayan feature dalı biriktirme.

1Güncel hali algit pull
2Ne değişti bakgit status
3Kod incele (kalite)Kod Kalitesi
4Dosyaları hazırlagit add ilgili dosyalar
5Küçük commit yazgit commit -m "…"
6Uzağa göndergit push
7Gerekirse PR açgh pr create
Dokunma
